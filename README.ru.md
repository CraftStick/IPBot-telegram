# IP Info Bot

[English](README.md) · [Русский](README.ru.md)

Telegram-бот, который рассказывает всё об IP-адресе или домене: местоположение на интерактивной карте, провайдер и AS, WHOIS, inline-режим, интерфейс на английском и русском.

## Быстрый старт

> **Нужно:** Python 3.10+ и токен бота от [@BotFather](https://t.me/botfather).

**1. Установка**

```bash
git clone https://github.com/CraftStick/IPBot-telegram.git
cd IPBot-telegram
pip install -r ipbot/requirements.txt
```

**2. Добавьте токен** — переменной окружения:

```bash
export BOT_TOKEN="123456:ABC-DEF..."
```

или в файле конфигурации (он в `.gitignore`, поэтому токен не попадёт в репозиторий):

```bash
cp ipbot/config.example.py ipbot/config.py   # затем вставьте токен в config.py
```

**3. Запуск**

```bash
python ipbot/bot.py
```

> [!TIP]
> Чтобы `@your_bot 8.8.8.8` работал в любом чате, отправьте `/setinline` в [@BotFather](https://t.me/botfather), выберите бота и введите подсказку, например `IP-адрес или домен`.

## Docker

```bash
cp .env.example .env          # впишите токен в .env
docker compose up -d --build
```

В образе только код бота, он запускается от непривилегированного пользователя и автоматически перезапускается.

## Использование

Отправьте боту IP-адрес, домен или ссылку либо воспользуйтесь командой:

| Команда | Что делает |
|:--|:--|
| `/ip <адрес>` | Проверить IP-адрес или домен |
| `/info <адрес>` | То же, что `/ip` |
| `/help` | Как пользоваться ботом |
| `/start` | Приветствие |

**Попробуйте:** `8.8.8.8` · `2606:4700::1111` · `google.com` · `пример.рф` · `https://github.com/CraftStick`

В группах бот отвечает только на команды, чтобы не реагировать на каждое сообщение.

## Как это работает

| Данные | Источник | Примечания |
|:--|:--|:--|
| Геолокация, провайдер, AS, PTR, флаги | [ip-api.com](https://ip-api.com) | Бесплатно, без ключа; 45 запросов в минуту на бота — ответы кэшируются на 5 минут, а бот останавливается до лимита по квоте, которую сообщает ip-api |
| Резервная геолокация | [ipwho.is](https://ipwho.is) | Используется, если ip-api недоступен или лимит исчерпан; бесплатно, без ключа, 1 000 запросов в сутки; без имени хоста (PTR) и признака мобильной сети |
| Регистрация доменов | [RDAP](https://about.rdap.org/) → классический WHOIS | RDAP там, где его поддерживает зона, иначе WHOIS по порту 43; для `.ru` / `.рф` / `.su` в резерве `whois.nic.ru` |
| Местное время | [`tzdata`](https://pypi.org/project/tzdata/) | Одинаково работает в Linux, macOS, Windows и Docker |
| Telegram | [`pyTelegramBotAPI`](https://pypi.org/project/pyTelegramBotAPI/) | Long polling, вебхук и публичный сервер не нужны |

WHOIS запрашивается параллельно с геолокацией, поэтому домены не ждут дважды. Частные и зарезервированные адреса (`192.168.x.x`, `10.x.x.x`, `127.0.0.1`…) отклоняются сразу — у них нет публичного местоположения.

Inline-режим ждёт небольшой паузы в наборе, прежде чем что-то искать, поэтому `google.co` на пути к `google.com` не тратит запрос, и оставляет сообщениям и командам последние 10 запросов к ip-api в каждую минуту.

## FAQ

<details>
<summary><b>Может ли бот показать мой IP?</b></summary>

<br>

Нет — Telegram никогда не передаёт ботам IP-адреса пользователей. Откройте [ifconfig.me](https://ifconfig.me) и отправьте боту адрес, который там увидите.

</details>

<details>
<summary><b>Насколько точно определяется местоположение?</b></summary>

<br>

В лучшем случае до города. IP-геолокация показывает, где зарегистрирована сеть провайдера, а не где находится человек, поэтому на карте отображается приблизительная точка.

</details>

<details>
<summary><b>Почему для некоторых доменов нет раздела WHOIS?</b></summary>

<br>

Некоторые зоны (например, `.de`) вообще не публикуют даты регистрации. Для `.ru` / `.рф` / `.su`, если сервер реестра недоступен из вашей сети, резервный `whois.nic.ru` знает только домены, зарегистрированные через РУ-ЦЕНТР.

</details>

<details>
<summary><b>Что-то не работает</b></summary>

<br>

| Проблема | Решение |
|:--|:--|
| `Bot token is not set` | Задайте `BOT_TOKEN` или создайте `ipbot/config.py` из `config.example.py` |
| `Unauthorized` при запуске | Неверный токен — получите новый у @BotFather |
| Нет ответа на `/start` | Убедитесь, что бот запущен, а у машины есть доступ в интернет |
| `@your_bot` ничего не показывает в чатах | Inline-режим выключен — включите его командой `/setinline` в @BotFather |
| «Too many requests» | Исчерпаны лимиты и ip-api (45 запросов в минуту), и резервного ipwho.is (1 000 в сутки) — подождите минуту |

</details>
